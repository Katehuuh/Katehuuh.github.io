A transformer nobody trained

Every weight below was placed by hand, for a stated reason. No gradient descent, no dataset, no random init. It runs live in this page: type a sequence and it predicts the next token, because the weights spell out an induction circuit. Find where this token appeared before, and copy whatever followed it. Switch a part off and watch the ability die.

ablate:

head 0 · previous token

Query and key carry one fixed unit vector each; RoPE turns them by their position, so the score depends only on the gap i-j. Turning the query back by -θ first puts the peak on a gap of exactly 1. Two frequencies, θ₁=1.0 and θ₂=2.3, because one alone ties gap 0 with gap 2.

head 1 · induction

Query reads the current token, key reads the previous token that head 0 wrote at each earlier place. Both are one-hot, so the dot product is 1 on a match and 0 otherwise, times a scale of 12 to make the softmax commit. It lands on the token that followed the earlier copy, and the value path carries that token out.

residual stream

One row per position, one column per dimension, 31 of them. Four blocks, each with a job: T the token itself, P the previous token that head 0 delivers, C the guess that head 1 and the MLP write into, R the two unit vectors RoPE turns. Nothing is entangled, because nothing had to be squeezed by an optimiser.

mlp · key-value memories

One neuron per fact. Weights in read a single token direction, the bias sits at -0.5 so nothing else can wake it, weights out add 1.2 to one guess. Deliberately quieter than the head, so evidence in the sequence beats a memorised habit.

logits

Read straight off the C block. The start marker carries a -10 bias so it is never the answer. Flat bars mean the circuit found nothing, which is the honest output, not a failure.
