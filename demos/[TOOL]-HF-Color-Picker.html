For an agent, without a browser

This page cannot answer curl. GitHub Pages serves the file as written and curl never runs the JavaScript, so the same empty page comes back whatever you put in the query string. The data is one public API call away, though, and needs no key:

curl -s https://katehuuh.github.io/demos/hf-colors.sh | sh -s -- Luminia,WeReCooking -emoji

Prints AVAILABLE n/64 and every free colorFrom->colorTo pair, then USED with a count in brackets for repeats, then EMOJI if you pass -emoji. Needs curl and jq.
