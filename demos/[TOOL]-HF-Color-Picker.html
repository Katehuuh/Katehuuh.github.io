Linking straight to a result

?org=Luminia,WeReCooking on this page runs the scan on load and prints plain text instead of the cards. Add &emoji to list the emoji already taken. The bare form ?Luminia,WeReCooking works too.

That still needs a browser. GitHub Pages hands curl this file exactly as written and never runs any of it, so the same page comes back whatever you put in the query string.

So this file is also a shell script. It opens with an html comment, which the browser skips, so you can pipe the page straight into sh. One file, no server, no key:

curl -sg https://katehuuh.github.io/demos/[TOOL]-HF-Color-Picker.html | sh -s -- Luminia,WeReCooking -emoji 2>/dev/null

-g stops curl treating the brackets as a glob. 2>/dev/null hides the one line sh prints about the comment opener; the script's own messages go to stdout so you still see them. Set HF_TOKEN for a higher rate limit.

Prints AVAILABLE n/64 then every free pair, then USED with a count in brackets for repeats, then EMOJI if you asked. Needs curl and jq.
